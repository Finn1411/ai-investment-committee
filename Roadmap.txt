Proposed Roadmap: Weeks 5–9+
Week 5 — Backtesting & Calibration Engine
"Does the system's confidence actually match reality?"

Goal: Build the anti-self-deception layer. Track every prediction, score accuracy, expose when the system is overconfident.

Prediction Journal — already logging. Add actual_return field for resolved predictions
Brier Score — probability calibration: if system says 70% chance of positive return, it should be right ~70% of the time
Hit Rate by Rating — what % of BUY calls outperform? AVOID calls avoid drawdowns?
Alpha vs Benchmark — do recommendations beat the S&P 500?
Confidence Calibration Chart — are 90% confidence calls actually right 90% of the time?

python -m finance_agent backtest --resolve AAPL --actual-return 0.12
python -m finance_agent backtest --stats
Week 6 — Intelligence Upgrades
"Make the agents smarter and the analysis deeper."

Goal: Add data sources and analytical depth that improve report quality.

Macro Regime Detection — VIX level, yield curve shape, inflation regime. BearAnalyst should be more aggressive in risk-off environments
Peer / Sector Comparison — when analyzing PLTR, automatically compare vs CRM, SNOW, MDB. Adds crucial relative valuation context
News Sentiment Layer — fetch recent headlines (via free API), score sentiment, feed as context to EarningsAnalyst
Earnings Calendar — flag upcoming earnings dates as risk events in the report
Insider Transactions — unusually large insider sells are a warning signal

New Ideas Beyond the Original Masterplan
💡 Committee Memory
Store past verdicts and show trend: "MSFT was HOLD last month, now HOLD — no change" vs "PLTR was BUY last month, now HOLD — degrading thesis."

💡 Thesis Conflict Detection
When the same ticker is analyzed twice, automatically compare theses and flag contradictions. Prevents the system from silently flip-flopping.

💡 "Why did the rating change?" Explainer
When a rating changes between runs, generate a diff-style explanation: "Score dropped 1.2 pts because FCF margin fell from 46.9% → 38.2% and BearAnalyst raised threat level."

💡 Scenario Stress Testing
Let the user drag a slider: "What if revenue growth falls to 20%?" → recalculate scenario probabilities in real-time without a new LLM call.

IMPORTANT

Week 7 (UI) has the highest return on investment for your goal of showing this to friends. A beautiful web interface makes the tool feel real and accessible. I'd recommend doing a lightweight version of backtesting (Week 5) first for intellectual integrity, then jumping to the UI (Week 7) before adding more data sources.

The FastAPI backend for the UI takes roughly 1–2 hours to wire up since the engine is already built. The React frontend is where most of the creative work happens. You'll be able to show a running prototype to friends within a single session.
